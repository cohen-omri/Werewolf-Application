# Werewolf Mobile Game 

A real-time, multiplayer Android application bringing the classic *One Night Ultimate Werewolf* card game to mobile. 

Built as a final High School Software Engineering project, this application features a custom-built Java server and a native Android client communicating via WebSockets to keep all players perfectly synced during the day and night phases of the game.

### The Team & Roles
* **Tamar Porath (@Tamar-Porath):** Lead Client Developer. Built the native Android app in Java using Android Studio. Responsible for the UI/UX, client-side game logic, and socket connection handling.
* **Omri Cohen (@cohen-omri):** Lead Server Developer. Built the Java backend using IntelliJ, handling the core game engine, Firebase/Firestore database integration, and multi-user socket broadcasting.

### Technical Features
* **Real-Time Multiplayer:** Built using Socket client-server communication to sync game states across all connected devices instantly.
* **Cloud Database:** Integrated Firebase and Firestore API for robust user data management and session handling.
* **Native Android UI:** A fully custom, interactive user interface designed to make role reveals, voting, and game phases intuitive.
